# Adventure Land HD

Adventure Land HD ersetzt ausschließlich visuelle Assets. Gameplay, Netzwerk, Persistenz und Server bleiben original.

> Alles, was das Spiel tut, bleibt original. Nur die Darstellung wird modernisiert.

## Standard

**8× ist der Standard für neue HD-Assets.** Kleinere Faktoren brauchen einen expliziten technischen Ausnahmegrund.
