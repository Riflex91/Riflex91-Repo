# HD Assets

Hier werden später ausschließlich neue HD-Ersatzassets abgelegt. Originalgrafiken und Gameplay-Dateien werden nicht kopiert.

Geplante Familien: `characters/`, `monsters-npcs/`, `world/`, `ui/`, `items/`, `vfx/`, `fonts/`.

Ein Asset wird erst aufgenommen, nachdem Phase 2 seinen Kompatibilitätsvertrag definiert hat.
