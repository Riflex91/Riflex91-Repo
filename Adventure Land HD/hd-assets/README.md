# HD Assets

Hier liegen ausschließlich neue HD-Ersatzassets. Originalgrafiken und Gameplay-Dateien werden nicht kopiert.

## Standard

**8× ist der Standard für neue Assets.**

Dateinamen verwenden den Pixi-kompatiblen Suffix `@8x`, zum Beispiel:

```text
characters/jubchan_1@8x.png
```

Andere Faktoren von 2× bis 7× sind nur als dokumentierte Ausnahme zulässig und benötigen im Manifest `scaleExceptionReason`.

Geplante Familien: `characters/`, `monsters-npcs/`, `world/`, `ui/`, `items/`, `vfx/`, `fonts/`.
