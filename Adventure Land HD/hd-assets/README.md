# HD Assets

Nur kompatible visuelle Ersatzassets; keine Gameplay-Dateien.

## Standard

Neue Assets: **8×** physische Auflösung und `@8x` im Dateinamen.

Andere Faktoren benötigen im Manifest einen dokumentierten `scaleExceptionReason`.

Familien: `characters/`, `monsters-npcs/`, `world/`, `ui/`, `items/`, `vfx/`, `fonts/`.
