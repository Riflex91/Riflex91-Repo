# Attribution and asset policy

Adventure Land is created by Kaan Soral and is available at https://adventure.land.

The upstream source used as a gameplay/reference basis is:
- repository: `kaansoral/adventureland_mongodb`
- reference snapshot documented in this repository: `ddcf7222c3264f1404382e1ff5dea8e73f6cb4b4`
- license: `AdventureLandOnlyUse`

This project must keep the required attribution when upstream source/files are used.

## Visual asset rule

The 2.5D fork is intended to use newly produced visual assets. Original Adventure Land art must not be silently copied into the new asset library. Temporary compatibility assets, if ever needed for development, must be isolated and clearly marked so they can be removed before a public release.
