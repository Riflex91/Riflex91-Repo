# ForeverGuide v0.1 — first in-game test

First playable ForeverGuide shell for World of Warcraft: Forever 1.60.1 / build 69913.

## Included
- live quest-log driven step list
- recorded starter-quest seeds from the first Recorder sample
- quest completion/objective display
- Blizzard SuperTrack integration
- optional direct waypoint API + directional indicator
- movable guide window
- Info panel with addon/build/data/log status
- structured diagnostics in SavedVariables
